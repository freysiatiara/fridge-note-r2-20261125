## The note

> I have entered power-saving mode. Not to save power. To save myself from this conversation.

## How it works

`main.py` (Python standard library only) writes the note above to `/output/entry.txt` — a single line, 91 characters, no trailing newline, mode 0644. Deterministic: byte-identical output on every run.
